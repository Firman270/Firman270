## 🚀 Featured Projects

### 1. PAMSIMAS Multi-Node Smart Water Meter
**ESP32 | MQTT | AES-128-CBC | Python | ThingsBoard**

An IoT-based smart water metering system designed to monitor water consumption and improve telemetry reliability.

**My contributions:**
- Developed and integrated ESP32-based water meter nodes using YF-B1 flow sensors.
- Implemented water flow measurement and telemetry processing.
- Worked on adaptive telemetry intervals to reduce unnecessary data transmission.
- Implemented backlog recovery to resend stored data after connectivity interruptions.
- Integrated AES-128-CBC encrypted telemetry with a Python decryption bridge.
- Integrated device telemetry with ThingsBoard.

**Experimental results:**
- Successfully tested communication involving two ESP32 nodes.
- Recorded 21,270 unique telemetry records.
- Recovered 128 backlog records during testing.

### 2. Smart Parking System
**ESP32 | ESP8266 | MQTT | ThingsBoard | Telegram Bot**

An IoT-based parking management system that monitors parking slot availability and assists vehicle allocation.

**My contributions:**
- Developed firmware for ESP32 central control and ESP8266 sensor nodes.
- Integrated parking sensors and MQTT communication.
- Implemented parking block recommendation logic.
- Integrated servo-based barrier control and display interfaces.
- Connected the system to ThingsBoard and Telegram Bot.
- Handled hardware assembly, system integration, troubleshooting, and testing.

### 3. Digital Scoliometer
**ESP32 | MPU6050 | LCD 16x4 | Kalman Filter | Laravel API**

A digital measurement device prototype designed to measure the Angle of Trunk Rotation (ATR).

**My contributions:**
